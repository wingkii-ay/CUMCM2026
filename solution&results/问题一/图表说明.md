# 问题一图表与数据说明

所有图使用附件1的144个10分钟段及确定性求解结果；无抽样、无随机重复实验，不附统计误差棒。时间按区间右端点映射，绘制功率曲线时用区间中点定位。运行储电量图显示区间端点。

图表均采用Python、6.3×3.9英寸、300 DPI PNG与可编辑文字SVG，单图单面板；配套灰度预览位于figures/_qa。统一样式与布局/设计校验使用技能提供的plot_style.py。数据剖析已确认144行、无数值缺失；slot是时间索引，不采用自动剖析工具建议的对数轴。大充放电动作受调度约束驱动，不能按IQR标记将它们删除。

| 图 | 核心论点 | 图型与证据 |
|---|---|---|
| raw_q1_supply | 午间光伏与负载形成可调配能量 | 原始负载/预测光伏功率曲线 |
| raw_q1_price_distribution | 当天144段包含不同价位 | 12箱频数直方图；箱高是时段数量，不是概率 |
| raw_q1_price_netload | 电价和净负载不是同一变量 | 144段一一对应散点，不作因果推断 |
| process_q1_storage | 储电量始终在1200–10800范围并恢复6000 | 状态轨迹及上下限 |
| process_q1_actions | 同时段充放互斥 | 双向功率柱；放电负号仅表示方向 |
| process_q1_losses | 实际运行有累计效率损耗 | 逐段0.1c+(1/0.9−1)b累计 |
| result_q1_purchase | 得到完整144段购电计划 | 每段购电电量阶梯图 |
| result_q1_cost | 同负载/光伏/端点下储能节省费用 | 两个确定性方案的实际费用横柱，不是样本均值 |
| result_q1_cumulative_cost | 费用在一天中的发生时间被调度改变 | 累计费用对照；不是逐时都保证节省 |
