# 问题四验收与复现记录

数学建模 skill 的 M1（模型）、P1（最小真实运行）及 P2（独立全量复现）均通过。结果为采用明确价格信息与结算假设的可行近似策略，不构成全局最优证明。

## 本次修正：0 时缺额定价

**改了一处**：`core.plan` 在 0 时对场景缺额的定价。原实现对所有时段一律按 5 倍应急计价，导致 0 时把承诺抬到 80% 分位；合同下节点后可增购的边际价是 1.5 倍，对应最优分位 67%。现按 `adj_from`/`adj_coef` 参数化：Q4-3 在 t≥36（6 时起首个调整节点之后）按 1.5 倍，t<36 及 Q4-2、`only0` 对照仍按 5 倍。节点之前的时段没有发布节点，缺口确实只能应急，保持 5 倍是对的。

**依据**：问题三 `battery_core.py:141` 对可调整时段正是按 1.5 倍定价，问题四未带过来；其 docstring 已明确警告此失效模式。诊断与取舍全过程见《优化方案.md》。

**效果**（主口径 334 天）：Q4-2 不变 14,410,716.10 元；Q4-3 由 14,534,969.71 降至 **14,329,837.01 元**（−205,132.70）。Q4-3 相对 Q4-2 由 **贵 124,253.61 元** 变为 **便宜 80,879.09 元**，方向与问题三一致。Q4-3 相对完美预知下界的差距由 13.71% 收到 12.10%。

**必须一并读的限制**（均已写入答案第五节）：

1. 该 8 万元优势在统计上不显著：公平边界下日均节省 240.86 元，95% 区间 [−73.12, 584.27] 跨零。
2. 它小于已声明理想化的价签：把实时观测整体回退一段后，Q4-3 反而比 Q4-2 贵 186,428 元。**不能宣称 Q4-3 在严格因果观测下仍更便宜。**
3. 修正使 `stale_all` 对照值上升 335,977 元（节点拿不到更新的光伏预报时，"可按 1.5 倍补缺额"的假定不成立）。因此 `all` 与 `stale_all` 之差（现为 541,914 元）应读作**更新的预报与它使日内调整真正可用的联合价值**，不是预报纯价值。
4. 缺额系数取 1.5 是合同量，不是按回测挑的。`study_shortcoef.py` 的扫描显示 `all` 在系数 2.0 处最低（比 1.5 低 15,320 元，0.11%），但按回测择优属于事后择优，本交付不采用。

三项审计不依赖 `solve.py` 自检，修正后全部重跑，并在独立复现目录上再跑一遍，两次结果完全一致：

## 阅读与使用

先阅读《问题四答案.md》，再查看 result4-2.xlsx 和 result4-3.xlsx。模型假设与算法详见《题目分析报告.md》，符号沿用并补充用户提供的《术语表格.md》；本次修正的诊断、已实施/已否决方案及其实测代价见《优化方案.md》。完整逐段账本、对照实验、敏感性分析和复现清单位于 results，图表位于 figures。

代码入口为 run_all.py；默认读取原始附件所在目录，**必须**用 `--input` 指定 C 题附件目录（默认值是原开发机的绝对路径）。需安装 requirements.txt 中的依赖。三项因果性审计与缺额系数扫描耗时较长，可单独运行，命令见《优化方案.md》第五节。`run_all.py` 与 `present.py` 中的 `skill_root()` 会自动在 `~/.claude/skills/math-modeling`、`~/.codex/skills/math-modeling` 及一个历史绝对路径中查找配套 skill。压缩包未包含用户原始附件。

## 解释边界

未来价格未知，按供电区间实际电价结算；该口径与充放效率、时间标签解释均已写入模型合同。不同结算口径需要重新计算。

本次修正的是**计划**用的缺额定价，不改实际计费口径（`J_42=Σp(G+5e)`、`J_43=Σp[G+1.5u+0.5v+5e]`）。

修正前"Q4-3 总费用高于 Q4-2"反映的是当日保守近似策略的局限，不是"额外信息必然有害"的证明；修正后符号反转，但**优势不显著、且小于段内理想化的价签**，因此也不能反向宣称 Q4-3 必然更便宜。更新信息的经济作用只在固定调整机会的对照下描述，且与 0 时缺额定价耦合（见上）。
